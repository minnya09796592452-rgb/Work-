# Recyclebin

Retained, non-primary diagnostic dumps. These are preserved for traceability and are not active implementation inputs.

- `CASTAWAY_NDK_CHECK.txt` — verbose NDK/package/header inventory.
- `CASTAWAY_NDK_LINK_TEST.txt` — first failed shared-library link attempt.
- `CASTAWAY_NDK_LINK_TEST2.txt` — successful AArch64 shared-library link and ELF inspection.
- `CASTAWAY_NDK_RUNTIME_TEST.txt` — successful dlopen/dlsym/function-call smoke test.

Use concise verified results under `docs/research/` and the current handoff for active decisions.
- `CASTAWAY_VULKAN_PREFLIGHT.txt` — Android 16 Vulkan headers, system loader, compiler, and package preflight.
